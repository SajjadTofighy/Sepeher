# نقشهٔ فرماندهی و تاریخچهٔ مسیر

نقشهٔ مرکز فرماندهی تمام عرض کارت را می‌گیرد. رخدادها روی نقشه شناورند و با دکمهٔ «رخدادها» جمع و باز می‌شوند. در موبایل ابتدا جمع هستند. دکمهٔ تمام‌صفحه، نقشه و کارت‌های شناور را همراه یکدیگر باز می‌کند؛ در مرورگر فاقد Fullscreen API از نمای تمام‌پنجره استفاده می‌شود و Escape آن را می‌بندد.

لایهٔ «مسیر حرکت خودروها» به‌صورت پیش‌فرض روشن است. دکمهٔ «مسیر خودروها» نمای نقشه را روی کل مسیرها تنظیم می‌کند؛ «بازگشت به امیدیه» دوباره معابر شهر را با بزرگ‌نمایی ۱۴ نشان می‌دهد. مسیر هر خودرو رنگ جداگانه دارد و مسیر انتخاب‌شده ضخیم‌تر است. بازپخش بر اساس زمان نقاط ثبت‌شده انجام می‌شود و نقاط آیندهٔ مسیر در بازپخش نشان داده نمی‌شوند. خطوط، اتصال مشاهدات GPS هستند؛ تطبیق مسیر با معابر انجام نمی‌شود. مسیرهای اولیه همچنان دادهٔ نمایشی هستند.

## ذخیره در پایتون

تاریخچه در SQLite و به‌صورت مستقل از وضعیت موقت عملیات ذخیره می‌شود:

- پیش‌فرض: `backend/data/tracks.sqlite3`
- تعیین مسیر: متغیر محیطی `SEPEHR_TRACK_DB`
- Docker Compose: حجم پایدار `track-data` در `/app/backend/data`
- بستن سرور، راه‌اندازی مجدد و `/api/v1/demo/reset` تاریخچه را پاک نمی‌کنند.
- نقاط نمونه فقط برای موجودیت بدون تاریخچه، در اولین راه‌اندازی اضافه می‌شوند.
- حذف خودکار تاریخچه وجود ندارد؛ تنظیم نمایشی `retention_days` باعث حذف این داده‌ها نمی‌شود.

ثبت یک موقعیت برای موجودیت موجود:

```http
POST /api/v1/assets/AST-001/positions
Content-Type: application/json

{"lon":49.702,"lat":30.757,"time":"2026-10-07T10:00:00Z","speed":24}
```

مختصات WGS84 با ترتیب طول و عرض جغرافیایی هستند. زمان باید منطقهٔ زمانی داشته باشد؛ در صورت حذف زمان، زمان UTC سرور استفاده می‌شود. سرعت اختیاری و برحسب کیلومتر بر ساعت است. موقعیت‌های دریافتی در نوبت بعدی به‌روزرسانی رابط (هر ۳ ثانیه) روی نقشه دیده می‌شوند. برای دریافت دادهٔ دستگاه واقعی باید آداپتور دستگاه این API را فراخوانی کند.

ارسال مجدد همان نقطه در همان زمان، ردیف تکراری نمی‌سازد. موقعیت یا سرعت متفاوت در همان زمان با کد ۴۰۹ رد می‌شود. زمان‌ها به UTC تبدیل و نقاط مرتب می‌شوند؛ دریافت یک نقطهٔ قدیمی، موقعیت فعلی خودرو را عقب نمی‌برد.

```http
GET /api/v1/assets/AST-001/track?since=2026-10-07T00:00:00Z&until=2026-10-08T00:00:00Z&limit=10000
```

بازه شامل هر دو انتها است. پیش‌فرض آخرین ۵۰۰ نقطه، سقف هر درخواست ۱۰۰۰۰ نقطه، با ترتیب زمانی صعودی است. نقشه نیز آخرین ۵۰۰ نقطهٔ هر موجودیت را دریافت می‌کند؛ نقاط قدیمی‌تر در پایگاه داده محفوظ‌اند و با فیلتر زمانی قابل دریافت هستند. قرارداد API در `docs/openapi.json` و `/docs` به‌روز شده است.

## بررسی

تست‌های Python پایگاه دادهٔ جداگانه دارند و ذخیره پس از بازکردن دوبارهٔ SQLite، حفظ تاریخچه پس از reset، ترتیب زمانی، ارسال تکراری، تعارض و اعتبارسنجی را پوشش می‌دهند. تست‌های Chrome عرض کامل نقشه، کارت شناور، کنترل لایهٔ مسیر، تمام‌صفحهٔ واقعی و جایگزین موبایل، و بازپخش مسیرهای طولانی با فاصله‌های زمانی نامساوی را بررسی می‌کنند.
