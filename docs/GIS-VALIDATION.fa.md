# اعتبارسنجی نقشهٔ امیدیه و GIS

تاریخ: ۷ اکتبر ۲۰۲۶، به وقت تهران.

- `npm run typecheck --prefix frontend`: موفق.
- `npm run build --prefix frontend`: موفق؛ خروجی قابل اجرا در `frontend/dist`.
- `.venv/bin/python -m pytest backend/tests -q`: ده آزمون موفق؛ شامل اعتبارسنجی نشانی، نام لایه، نسخه و شفافیت GIS و گردش‌کارهای موجود.
- در پوشهٔ `frontend`، `PLAYWRIGHT_CHANNEL=chrome npm run test:e2e`: دوازده آزمون موفق. چهار آزمون توابع جغرافیایی/GeoJSON/OGC و هشت آزمون مرورگر شامل ورود، انتخاب، خاموش‌کردن و خروجی GeoJSON، اندازه‌گیری، WMS/WFS، فرم تنظیمات، کنترل نقشه، حالت بدون WebGL، نمایش موبایل و گردش‌کارهای حوادث و فرمان تجهیزات.

بررسی زندهٔ Chrome با `node scripts-map-preview.mjs` انجام شد. منبع OpenFreeMap، کاشی‌های واقعی امیدیه و فونت‌های برچسب فارسی پاسخ HTTP 200 دادند و خطای JavaScript در بارگذاری نقشه ثبت نشد. نمای خیابانی OSM هم بدون خطای مرورگر بررسی شد. تصاویر نهایی در `docs/screenshots/omidiyeh-night.png`، `omidiyeh-gis.png` و `omidiyeh-street.png` ذخیره شدند.

آزمون‌های WMS/WFS از پاسخ‌های کنترل‌شده در مرورگر استفاده می‌کنند؛ ساخت درخواست، محدودهٔ کاشی، نسخه، نمایش عارضه و اتصال تنظیمات به نقشه بررسی شده است. چون نشانی سرویس سازمانی ارائه نشده، اتصال به سرویس اختصاصی سازمان هنوز آزموده نشده است. دسترسی، CRS و CORS آن سرویس باید هنگام واردکردن نشانی واقعی بررسی شود.
