# تطبیق قابلیت‌ها با طرح

بازبینی ۲۰۲۶-۱۰-۰۸: [گزارش کامل تطبیق و نواقص باقی‌مانده](DESIGN-REVIEW.fa.md).

تعریف «پیاده‌سازی نمایشی»: فرم، مسیر کاربر و API قابل اجرا وجود دارد؛ ورودی‌ها و رفتار دستگاه/تحلیل ساختگی‌اند. این جدول ادعای آمادگی عملیاتی نیست.

موتور سیاست برای نه شرط و دریافت موقعیت HTTP و ذخیره پایدار مسیر موجود است. بازسازی جامع تاریخچه، ویدئو، اتصال LDAP/AD واقعی، درگاه پروتکل دستگاه/پیامک، ذخیره پایدار عملیات قدیمی، سه شرط دیگر، تشخیص ناهنجاری خودروی سازمانی و LLM همچنان ناقص یا نمایشی‌اند. هیچ شبیه‌سازی با اتصال واقعی معرفی نشده است.

| شواهد اسکن و زمان | `fieldstore.scans`، `app/tour.py` و `routers/stations.py` | لنگر X-Server-Time، پنج شاهد و trust قطعی، ثبت append-only، retry با client_id، GPS کمکی و پرچم جهش/دقت مشکوک؛ اسکن دستی/UID کم‌اعتماد در انتظار بازبینی |
| خطرهای ایستگاه | StationVisit و FieldZone | تأیید گازسنج پیش از H2S/flammable، پرچم دستگاه فاقد Ex و تماس محلی؛ تصمیم مجوز گوشی در منطقه Ex همچنان با HSE است |
| PIN اضطرار و ایمنی فرد تنها | `field_safety.py` و `/tour/unlock` | پاسخ PIN عادی/اضطرار برای نگهبان یکسان؛ گزارش اجبار فقط در صف نقش امنیتی؛ دیرکرد check-in گشت پیاده یافته shadow؛ تشخیص حرکت/سقوط و شمارش معکوس باید در UI میدانی اجرا شوند |
| اعلام خطر و رسید | `/tour/safety-events` و `/incidents/{id}/ack` | رسید سرور جدا از رسید اپراتور؛ SOS صریح پرونده می‌سازد ولی اعزام نمی‌کند؛ man_down گزارش‌شده یافته shadow است؛ تشدید بی‌رسید در SSE امنیتی |
| حضورشماری | `/tour/musters` | درخواست مسئول حراست، پاسخ safe/need_help و فهرست بی‌پاسخ‌ها؛ اعلان SSE با دید محدود نگهبان |
| UI و سخت‌افزار | `docs/UI-HANDOFF.fa.md` | توسعه UI مجزا است؛ Wake Lock، DeviceMotionEvent، قفل محلی، آزمون گوشی/تگ و آفلاین امن در این تحویل اجرا نشده‌اند |

## فاز چهار: آفلاین امن

| قابلیت | پیاده‌سازی | مرز تحویل |
|---|---|---|
| رکورد امضاشده | `app/offline.py` و `SignedQueueRecord` | HMAC دستگاه فعال برای هر رکورد دریافت‌شده؛ امضای نامعتبر/دستگاه باطل‌شده رد و ممیزی می‌شود؛ صف و CryptoKey کلاینت هنوز ساخته نشده‌اند |
| اضطرار بدون نشست معتبر | `/tour/offline/emergency` | SOS/duress/man_down امضاشده با توکن منقضی یا غایب پذیرفته و `auth_expired` برای مرکز ثبت می‌شود؛ مالکیت گشت از دستگاه فعال بررسی می‌شود |
| اسکن و زمان آفلاین | `/tour/offline/scans` و `app/tour.py` | همان اعتبار تگ و بازدید موجود؛ `offline_too_long` سطح اعتماد را حداکثر medium و `clock_regressed` را مستند می‌کند |
| موقعیت دسته‌ای | `/assets/{id}/positions:batch` | هر موقعیت HMAC مستقل و مالکیت نگهبان؛ همان مسیر پایدار TrackStore استفاده می‌شود؛ retry رکورد یکسان ایمن است |
| رمزنگاری و صف روی گوشی | `docs/UI-HANDOFF.fa.md` | Cache Storage فقط پوسته، IDB رمز‌شده، پاک‌سازی، اولویت، backoff و آزمون گوشی کار تیم مستقل UI است؛ report/media تا فاز پنج API تخلیه ندارد |

## فاز پنج: پیام، رسانه و گزارش‌های میدانی

| قابلیت | پیاده‌سازی | مرز تحویل |
|---|---|---|
| آپلود قطعه‌ای و زنجیره حفاظت ادله | `routers/field_comms.py` و `field_media.py` | شروع/قطعه/وضعیت/پایان با offset سخت‌گیر، ازسرگیری، sha256 کل فایل، زمان دریافت سرور، ثبت‌کننده و دستگاه؛ PUT یکجا فقط زیر سقف کوچک؛ بدون multipart. روی شبکه واقعی میدان آزموده نشده |
| ضبط و حریم تصویر | `FieldApp` و `capture-policy` | عکس با getUserMedia و canvas، ویدئو/صوت با MediaRecorder و سقف مدت و bitrate؛ نسخه‌ای در گالری یا دانلود نوشته نمی‌شود؛ در محوطه/ایستگاه بدون مجوز فقط متن و صوت. روی گوشی سازمانی آزموده نشده |
| دسترسی و نشان‌آب | `GET /media/{id}/content` و کنسول | no-store و audit هر مشاهده؛ رسانه خسارت/مهمات/پهپاد فقط مدیر حراست، غیرقابل خروجی و حذف از گوشی پس از ارسال؛ نشان‌آب شمسی/نگهبان/ایستگاه/بیننده هنگام نمایش و خروجی تصویر |
| نگهداری و legal_hold | worker و `media_retention_days` | حذف فقط با job نگهداری و audit؛ پیوست پرونده نگهداری قانونی خودکار دارد |
| دسته و مسیریابی گزارش | `/tour/reports` و `report_routing` | هفت دسته، مخاطب حراست/HSE/بهره‌برداری با رسید انسانی هر واحد؛ دستور ایمنی ثابت؛ ارسال بیرونی به واحدها وجود ندارد |
| پیام فوری و اعلان محوطه | `/messages` | رسید صریح نگهبان، تکرار هشدار در اپ تا رسید، تشدید زمان‌دار سرپرست و مسئول حراست، نمای رسید همه گیرندگان |
| ارسال آفلاین گزارش | `/tour/offline/reports` | رکورد امضاشده دستگاه با پرچم offline_too_long و clock_regressed؛ صف رمزشده IndexedDB کلاینت (فاز ۴) هنوز ساخته نشده است |
